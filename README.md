# LLM_interviewer

A Flask-based project for building an interviewer application powered by LLMs.

## Project Structure

```
LLM_interviewer/
│
├── app/
│   ├── __init__.py         # Initialize Flask app and extensions
│   ├── routes.py           # Application routes (views)
│   ├── models.py           # Database models (ORM classes)
│   ├── forms.py            # WTForms classes (if using forms)
│   ├── static/             # Static files (CSS, JS, images)
│   └── templates/          # Jinja2 HTML templates
│
├── tests/
│   └── test_basic.py       # Example test file
│
├── migrations/             # Database migration scripts (if using Flask-Migrate)
│
├── requirements.txt        # Python dependencies
├── config.py               # Configuration settings
├── run.py                  # Entry point to run the app
└── README.md               # Project documentation
```
